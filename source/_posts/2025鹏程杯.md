## 2025鹏程杯-whiteout
题目提示：一份离线备份的 Docker 镜像
### 解题思路

首先需要了解一下 Docker 镜像的分层结构，层级的文件都是只读不能进行修改，最底层是基础系统层；中间层则是添加的软件配置文件和含有 flag 的文件等；最上层则是构建层，装饰

拿到附件是一个名为 whiteout 的压缩包
![](./2026-04-13-09-42-13.png)

Docker 通过 docker save 导出的 tar 包包含了镜像的所有分层、配置信息，所以需要解压查看核心分层的配置文件`manifest.json`该文件记录了镜像的层顺序 

在 kali 中用命令进行解压拿到镜像 tar 包

```cmd
unzip whiteout.zip
mkdir image && tar -xf imagr.tar -C image
cd image
ls -la
```

进行解压后发现有多个层级文件及核心配置文件`manifest.json`确认层的顺序，必须先看核心配置文件
![](./2026-04-13-09-43-04.png)
查看`manifest.json`获取镜像层的顺序 底层至上层
![](./2026-04-14-17-38-44.png)

查找 whiteout 隐藏文件，确定被标记删除/隐藏的文件路径，直接查看最后一行文件包含 .wh 的内容，.wh. 文件一定在顶层，效率最高，所以直接查顶层的文件

![](./2026-04-14-20-04-57.png)

查找后从下层提取被隐藏也就是被删除的源文件

![](./2026-04-14-20-24-54.png)

查看文件类型这里为二进制加密文件
![](./2026-04-14-22-07-13.png)

单字节 XOR 解密，可以直接给网络厨师进行解密，这里我写了一个py脚本

```py
with open('extract/opt/.data/.logs/syslog.bin', 'rb') as f:
    cipher_data = f.read()
print('最终flag：', bytes([b ^ 0x37 for b in cipher_data]).decode())
```

![](./2026-04-14-22-09-52.png)

最后得出flag为`flag{Docker_whiteout_forensics_is_fun}`

## 2025鹏程杯-Hidden

题目提示：我们从一名嫌疑人的硬盘中恢复了这张图片。我们认为它不仅仅是一张普通的图片。对文件属性的初步分析没有结果，但我们怀疑需要一个密码才能解开秘密。请找出其中隐藏的数据。
### 解题思路
拿到附件后解压后后拿到的是一张为 treasure.bmp 的图片
![](./treasure.bmp)
题目明确排除了文件属性，直接检查是否有明文数据，使用`strings`命令查看文件尾部信息
![](./2026-04-10-08-59-08.png)
输出了很多乱码，初步判断使用了加密隐写工具
题目也提示了'需要一个密码'，BMP适合LSB隐写，使用`zsteg`工具对图片的所有通道进行探测；命令`zsteg -a treasure.bmp`；看出为`rgb`通道，找出了一条干净的明文`PixelWhisper`（像素低语），判定解密需要`Passphrase`
![](./2026-04-10-09-02-44.png)
使用隐写工具进行解密，`steghide`是处理此类带密码保护图片的工具

```bash
steghide extract -sf treasure.bmp -p "PixelWhisper"
```
执行完命令后回吐出隐藏文件 flag.txt ，直接cat
![](./2026-04-10-09-12-01.png)
找到flag为flag{a9a3c2872e428b6d859a0e63458a43f8}

## 2025鹏程杯-blue
题目提示：蓝色的世界。
### 解题思路

拿到附件是一张后缀为 .png 的图片，什么都看不清

![](./blue.png)

查看下图片信息，发现没有明显的附件文件、metadata，那就可以确定该题为图片隐写分析
![](./2026-04-27-10-41-40.png)

题目的提示强调 blue，重点检查蓝色通道，用py脚本分离通道，取每个像素 B 通道的高4位拼成十六进制流

```python
from PIL import Image

img = Image.open( "blue.png").convert("RGB")

pixels = img.getdata()

s = "".join(f"{(p[2] >> 4):x}" for p in pixels)

if len(s) % 2 != 0:
    s += "0" 

with open("oo.zip", "wb") as f:
    f.write(bytes.fromhex(s))

print(f"提取完成！共处理了 {len(s)} 个十六进制字符。")
```

生成了 oo.zip 的一个压缩包，开头是`504b304`；里面有 xor.png 加密文件，文件头已知，直接对 ZipCrypto 做已知明文攻击

![](./2026-05-13-08-54-33.png)

使用 bkcrack 进行明文攻击

```bash
bkcrack -C oo.zip -c xor.png -x 0 89504e470d0a1a0a0000000d4948445200
```

拿到了keys

![](./2026-05-13-09-12-23.png)

对keys进行解密

![](./2026-05-13-09-18-02.png)

得到 xor.png ，但末尾有另一个png，用签名 89504e470d0a1a0a 进行分离

```python
data = open("xor.png", "rb").read()
sig = b"\x89PNG\r\n\x1a\n"
offs = [i for i in range(len(data)) if data.startswith(sig, i)]
print(offs)

open("tail.png", "wb").write(data[offs[1]:])
```

文件名提示 xor ，尝试异或，把 xor.png 和分离出的 tail.png 逐像素异或：

```py
from PIL import Image
import numpy as np

img1 = Image.open("xor.png")
img2 = Image.open("tail.png")

arr = np.array(img1) ^ np.array(img2)
Image.fromarray(arr).save("xor1.png")
```

得到 xor1.png ，最后看到图上有盲水印特征，用双图盲水印工具解，这里可以用工具可以写py脚本，我这里使用了工具，建议下载压缩包解压，拉取会受网络影响而失败

```bash
wget -O BlindWaterMark.zip https://codeload.github.com/chishaxie/BlindWaterMark/zip/refs/heads/master

unzip BlindWaterMark.zip

# 解压后开始解 注意该工具有两个py脚本，其中 bwm.py 用于 python2 ， bwmforpy3.py 用于 python3
cd BlindWaterMark

python3 bwmforpy3.py decode /home/kali/MISC/blue/xor1.png /home/kali/MISC/blue/xor.png /home/kali/MISC/blue/flag_watermark.png
```

最后拿到flag
