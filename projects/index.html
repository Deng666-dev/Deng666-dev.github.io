LiteWebScan

面向 DVWA 等授权靶场的轻量级 Web 漏洞学习扫描器，用 Python 练习登录态维持、参数注入、SQLi/XSS 探测和 Markdown 报告生成。

Python requests DVWA SQLi / XSS
  • 自动请求 DVWA 登录页并提取 user_token。
  • 使用 requests.Session 维持 Cookie 与安全等级。
  • 扫描结束后生成 Markdown 漏洞报告。
